# Prospective missingness revision after the ingestion gate

10 September 2026. Version 0.2 failed its prespecified finite-data ingestion gate before any model score was produced. The following is a proposed, documented v0.3 revision based on source axes and finite/nonfinite masks only. It is not the original preregistered rule, and no claim of external preregistration should be made.

## What the mask audit establishes

The annotation intersection contains 2,052 targets and 6,642 genes. Common-coordinate missingness ranges from 0.076% in K562 to 0.553% in RPE1. Every target retains finite truth in every context. However, only 419 targets are fully finite across all four contexts: requiring complete targets would discard approximately 80% of the panel because a small number of missing coordinates can invalidate an entire target. Complete-target filtering is therefore a strongly selected secondary diagnostic, not the recommended primary repair.

For outer folds, every target has some genes with at least two observed source contexts. Finite held-out coordinates with no source measurement do exist: 858 in K562, 68 in RPE1, 71 in HepG2 and 63 in Jurkat. They must remain in the score under the declared unsupported-coordinate prediction. The successful audit is saved in `missingness-review.json`; its script reads only availability masks and reports no effect sizes, predictions or scores. A later attempt to add NaN-versus-infinity and inner-pair counts failed at the memory-map opening step; those additional checks were not completed in that audit artifact.

## Recommended minimal rule

1. Retain the annotation-defined common panel. Treat archive NA/NaN as an unavailable published effect, never as an observed zero. Distinguish positive/negative infinity from declared missing tokens and fail on infinite numeric values rather than quietly accepting a numerical error as biological missingness.
2. Within each training split, calculate a separate finite source count `n_j` and finite-source mean `mu_j` for each target/gene. Where n=0, predict zero and mark that coordinate unsupported. This is a prediction fallback, not imputation of an observed outcome. Where n=1, a mean exists but cross-context variance does not.
3. For each target define `J={j:n_j>=2}` using training data only. Let `s_j²` be sample variance with ddof=1. Compute `M=mean_J(mu_j²)` and `q=mean_J(s_j²/n_j)`. Use `w=max(1-lambda*q/M,0)` when M>0, and w=0 when M=0. A single common n is incorrect when genes have different availability. Apply this target weight to all supported coordinates; n=0 coordinates remain zero. This extension explicitly assumes the reliable-coordinate shrinkage weight can be shared with one-source coordinates.
4. If J is empty, use the unshrunk available-source mean as a simple fixed fallback, record variance as undefined, and rank the target last for disagreement-based retention. Do not interpret undefined variance as zero risk. The current outer masks have no such targets, but inner-fold code must still define the case. Keep lambda=0 identically equal to target mean, including all-zero inputs.
5. The zero, target-mean and globally shrunk target-mean predictions use the same target-specific support mask. For the target-agnostic global template, specify the averaging separately: average available targets within each training context/gene, then available context means equally. Its information comes from other targets and need not be falsely marked absent just because one target has n=0. Every prediction must still be finite.
6. In each inner and outer scorer, use only finite truth. For every target, average squared error over its finite truth genes, using the exact same mask and denominator for every model. Then average scorable targets equally and contexts equally. Finite truth coordinates with n=0 stay included. A target with no finite truth is unscorable, reported explicitly and never silently dropped from counts; the current outer masks have none. Do not additionally require observed training truth to admit a coordinate to the primary score.
7. For training disagreement rankings, use V=mean_J(s_j²), not an average padded with zero variances for unsupported genes. Report the number/fraction of variance-eligible genes and n=0/1/2/3 coordinate counts. A high missing fraction can affect rankings; do not call the resulting score calibrated uncertainty. On every retained mask compare candidate, zero, target mean and global shrinkage, with magnitude/random retention controls.
8. Permute target records with their availability masks in the negative control. Record resulting support counts. This breaks the correspondence of both response patterns and availability patterns, so it is a target-record control, not proof that effect magnitudes alone account for any difference. Never permute the held-out truth or its scoring mask.

The standard held-out poisoning test should perturb finite held-out numerical values while keeping annotations fixed and require identical predictions, selected hyperparameters and training support/ranks. Changing only held-out availability must also leave these unchanged; it may change which truth coordinates can be scored. Save predictions before opening scoring truth.

## Meaning of the revised result

The estimand becomes error on **published, finite, estimable LFC coordinates** for the common annotation panel, with equal weight per target and context. It is not error on all latent biological effects. DE pipelines may omit estimates for outcome-dependent reasons, so this missingness is not assumed random. Report finite truth denominators, unsupported finite truth counts and source preprocessing; no imputation model can manufacture missing ground truth.

This revision preserves the practical transfer comparison with minimal extra machinery. It should be frozen and hashed before fitting, retaining v0.2 and its gate failure as history. No revision of shrinkage grids, retention scores or primary comparators is justified by this missingness event. A complete-case target diagnostic may be reported separately if prespecified now, with its 419-target selection made explicit; it cannot replace the all-target primary result after seeing scores.
