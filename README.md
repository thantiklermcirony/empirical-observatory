# Empirical Architecture Observatory

**Daniel John Murray · Models, measurements and experiments**

The laboratory repository for a programme studying bounded systems, hidden state, finite resources and useful action. The aim is to connect an explanation of a system with a calculation, a discriminating experiment and a result that can change the explanation.

**[Explore the public research exhibits](https://boundedness-atlas.madmanmuzza.chatgpt.site/)** · [Scientific foundations](https://github.com/thantiklermcirony/empirical-architecture) · [Predictions](https://boundedness-atlas.madmanmuzza.chatgpt.site/predictions/) · [Contribute](CONTRIBUTING.md)

## What a visitor should find

A question; the model and its assumptions; an observable consequence; the measurement or comparison; and the resulting conclusion. The programme includes mathematical work, published biological models, synthetic demonstrations, completed empirical comparisons and software contributions. ## How to use this repository

For research, start with the relevant row above and follow that package's reproduction instructions. The laboratory contains several independently scoped packages; no single test command verifies every scientific claim.

For the application, use the scripts and dependency versions declared in [package.json](package.json). Hosting uses the project's recorded deployment configuration. A source merge, a deployed route, a successful software test and an empirical result are separate milestones.

For a new investigation, specify the physical quantities and their units, the observation model, the alternative explanation and the untouched outcome that can distinguish them. Publish the resulting failure or success with its original comparison. A proposed connection becomes a scientific result only when the necessary derivation or measurement supports it.
