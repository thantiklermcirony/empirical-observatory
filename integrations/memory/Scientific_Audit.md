# Independent scientific and reproducibility audit

Inspected Observatory engine 0.1.0 on 2026-09-09. The checkout was read-only for this agent. Findings below describe the source snapshot in `audit-source-hashes.json`; the owner may already have fixed them. `reproduce_findings.mjs` generates `audit-reproduction.json` from the path supplied at execution. Existing Node tests: **18 passed, 0 failed**. Passing those tests did not detect the issues below.

## Fix before publishing new evidence

**P1 — quantum state and first shot share the same random draw.** In `lib/engine/quantum.ts`, `mysteryState(seed)` selects a state from the first `random(seed)` draw, while `QuantumLab.sample` passes that same seed to the first measurement batch. Conditional on the selected state, shot 1 is therefore biased. Across 60,000 seeds, first Z-shot plus rates for `0,1,+,-,+i,-i` were `1,0,1,0,0,0`; declared probabilities were `.94,.06,.5,.5,.5,.5`. The Bayesian likelihood assumes independent Born samples, so it does not describe this first batch correctly. Use domain-separated state and shot streams, check conditional frequencies, and version the change so old records are not silently reinterpreted. The analytical/cross-library probability tests remain useful but do not test the sampling protocol.

**P1 — the exact alignment primitive fails identity near an endpoint.** `flow('alignment',1e-12,0)` returned approximately `1e-9`. Its call to the globally clipped `logit` changes the state even at zero duration. Use an unclipped interior log-odds computation in the exact primitive, with explicit endpoint handling, and reserve chart clipping for a separately named numerical diagnostic. Test identity, inverse, and composition at near-endpoint values as well as ordinary interior values. The current “exact flow” wording overstates the implementation for these inputs.

**P2 — quantum record configuration is not part of validation.** `validateRecord` accepted a completed quantum record with zero measurements and `{noise:999,budget:-1}`. Replay reads measurement-level noise and ignores the configuration, so a valid replay does not verify that the saved configuration describes the run. Validate fixed protocol fields, measurement counts/noise, budget, and completion requirements. Expose the replayed guess/correctness if the saved game outcome is being called verified. A source label supplied by a file is not physical provenance.

**P2 — duplicate signal timestamps can make a capture fail its own round trip.** `InstrumentDock` sorts each incoming packet but does not reject or deduplicate timestamps repeated within that packet. It can save such rows, while `validateRecord` correctly requires strict timestamp increase. Packet validation also omits string checks for device, unit, and channel names; malformed metadata can reach rendering. Reuse a shared schema validator for receipt and import, reject or explicitly deduplicate duplicates, and test round trips. Rejecting changed identity between polls is already implemented and is appropriate.

## Clarify before calling these scientific guarantees

**P2 — dwell is a mode-label constraint, not an actuator-sign constraint.** With TAO at `x=.1`, then `x=.9` 0.1 seconds later, mode remains `recover` but action changes from `+.8621` to `-.7143`, inside the declared 0.5-second dwell. This is consistent with the current formula: mode changes the multiplier, while error determines sign. If the intended contract concerns mode transitions only, say so. If it promises directional actuator dwell, implement and test that stronger semantics. Do not change it silently because that would change benchmark evidence.

**P2 — browser onset is dispatch time, not measured display onset.** BehaviourLab timestamps with `performance.now()` before `setTarget`, so measured reaction time includes React/render/display scheduling. The docs already acknowledge uncalibrated latency. Preserve that qualification; add requested-onset, committed-render, event timestamps and frame/visibility diagnostics before research use. Even an animation-frame timestamp is not a photodiode measurement. The browser clock can be monotonic without attesting when pixels became visible. [W3C High Resolution Time](https://www.w3.org/TR/hr-time-3/).

**P2 — observation-policy forecasts are descriptive examples.** Signal Bay has no learned AI model, only a last-outcome rule and a recent-six rule. Adaptive and fixed policies change the response window itself. A success-rate difference therefore cannot be interpreted as better learning or a new cognitive law. Existing Methods wording says this correctly; keep it in public summaries and papers. Hold out participants/sessions, freeze models, and account for condition order, practice, fatigue, and exclusions before inference.

**P2 — instrument timing does not yet support EEG/behaviour coupling.** Device timestamps and the browser performance clock have no measured transform. Synthetic BrainFlow acquisition and token/origin boundaries are integration checks; they are not EEG validation. Add a synchronization protocol, retained marker clock transforms and uncertainty, dropout counters, channel/unit/board metadata, and physical device validation before claiming closed-loop neuroscience. Report playback and IBM submission as untested paths until exercised.

## Manuscript and public-claim corrections

1. Attribute `[0,1]` plant invariance to the exact frozen-rate plant update, shared by all controllers. Outward-action suppression at `[.05,.95]` is not by itself an invariance proof for that smaller interval under drift and disturbances. The Methods section already makes the larger-interval distinction correctly.
2. Keep TAO as an implementation-derived synthetic fixture, not a reproduction of the original paper's benchmark. On the current report, PI has lower tracking MAE than TAO. Publish the full comparison and failures; do not imply global dominance. Four development and twelve public test seeds are a small known-family fixture, not independent external validation. New tuning requires fresh sealed evaluation seeds/families.
3. Label chart travel as coordinate-dependent; it is not physical work, energy, or an invariant geometric distance without an independently defined metric and units.
4. Quantum Tensors and Qiskit agreement checks standard circuit semantics. It is neither quantum advantage nor evidence for new quantum mechanics. The sampling bug shows why semantic tests and sampling tests are different obligations.
5. History/state representations and memory benchmarks are established. The included actual POPGym integration can make programme questions reproducible, but it does not establish conceptual novelty. Compare the proposed representation with predictive-state, belief-state, recurrent, and state-space approaches on matched tasks. [POPGym](https://github.com/proroklab/popgym), [Predictive Representations of State](https://proceedings.neurips.cc/paper/2001/hash/1e4d36177d71bbb3558e43af9577d70e-Abstract.html).
6. There is no defensible AI-market percentage or model-size reduction estimate yet. Such an estimate requires a specified new model and matched empirical quality/cost results. A delay register solving card recall cannot be extrapolated to language-model capability or market valuation.
7. Preserve separate evidence categories: theorem with assumptions; implementation test; synthetic diagnostic; independently measured experiment; hypothesis; speculative application. A shared interface across domains is useful engineering, but does not prove their states have identical physical meaning.
