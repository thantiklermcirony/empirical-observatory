HOW THIS GROWS

Each experiment is a contract: stimulus rules, timing, reference context, expected information, confounds, and a test that could fail. Add new protocols in experiments.json. The current runner supports target detection, switching, and recovery phases.

These first protocols are prototypes. The encyclopedia does not yet rank efficacy or choose a scientifically validated optimum next task.

DIRECT MUSE

The capture component uses Web Bluetooth through the pinned muse-js adapter. It aligns four-channel packets and records missing-packet boundaries. Muse 1/2/S support is claimed by the upstream library; this build has not been tested with your hardware. Newer Muse models require separate verification.

Start on desktop Chrome/Edge with Bluetooth enabled. Select “Muse · direct Bluetooth” in the workbench. Basic signal quality is not an electrode-impedance measurement; physiological and motion artifact validation remains necessary.

Supports TimeStamp, RAW_TP9, RAW_AF7, RAW_AF8, RAW_TP10.
