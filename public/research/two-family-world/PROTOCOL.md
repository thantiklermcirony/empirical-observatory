# Two-family world 0.1: development protocol

Written before inspecting held-out scores. This is an engineering prototype in an authored finite simulator, not evidence of emotion or a law of learning.

Development seeds: 101, 102, 103. Evaluation seeds: 1001 through 1012. Evaluation seeds are not used to select code, hyperparameters or success thresholds. Changes after evaluation must be labeled exploratory and use a new untouched set to claim confirmation. No external preregistration is claimed.

1. Transition prediction. Each agent trains on 600 ticks of random interactions. Freeze its network; score 250 ticks in a separately initialized random-action world (seed XOR 0x123456). Include unchanged initial networks, a training-set constant predictor, and a trained linear sigmoid comparator. All predictors receive the same action and available observations. Report normalized effect/utility MSE; it is not a probability calibration score. Require a lower paired mean error than the training-set constant to call the learned predictions useful here.
2. Control. After identical 600-tick random-action training, transfer the first six networks into freshly initialized, identical physical worlds (seed XOR 0x2201). Compare a frozen learned policy, a random policy, and a conventional need-first heuristic. All see the same physical variables and get the same action opportunities; their subsequent trajectories differ. Evaluate 200 ticks, with drought imposed for the last 100. Score mean squared shortfall below the designed 0.8 need target (lower is better). Preserve failures. The learned controller must beat random to demonstrate useful action selection; beating the conventional heuristic is a separate, stronger question.
3. Partner history. A SEPARATE controlled task gives two partners identical present appearance but help probabilities 0.9 and 0.2, with identities randomly permuted. Use 160 training observations, 400 held-out binary outcomes. Compare a partner-specific Beta(1,1) predictor with pooled observations after erasing identity. Repeat with equally reliable partners (0.55 each). Score Brier loss. This is a standard Bayesian memory demonstration, not the neural households' attachment result.
4. Cost probe. Help has designed benefit 0.4 and request costs 0.08 or 0.4. Check whether the partner predictor requests help only when its estimated expected benefit exceeds cost. This demonstrates an instrumental choice under supplied utilities; it cannot establish felt attachment, grief or consciousness.
5. Report all 12 seeds and paired mean differences with a 95% percentile bootstrap interval over seeds (10,000 resamples, seed 20260911). These intervals describe simulation-seed variation, not external biological validity. No significance screening or best-seed claims.

User-directed extension, still before evaluation: include a linear sigmoid controller with 140 parameters per agent versus the 1,004-parameter stack, and a fixed-attention control with the same architecture. Effective repertoire is exp(entropy) of observed need-bin/action contexts. Allocate relationship attention as 1 / (1 + (C-1)/16), leaving the underlying attribution records intact. Compare adaptive and fixed attention on the same physical deficit endpoint; a smaller mean alone is descriptive, and the paired interval must exclude zero to call the effect consistent across these seeds. Word–action utility is accumulated through real Möbius translations; a 32-event sequence store and a last-verb input preserve information that the commutative scalar accumulator loses. No universal optimality or sufficiency is assumed.

Development changed the policy from a direct utility regressor to revaluing predicted physical effects against current needs, with a 0.15 residual weight on the learned utility. This followed a documented transfer failure on development seeds. The separate prediction benchmark fits nonlinear and linear models to identical transition and replay examples with four SGD updates each. Synthetic transition MSE includes an unfamiliar drought condition. Control freezes neural weights only: designed memory filters continue to update.

The user then requested a self-written language and a durable personal world record. Each agent now coins its own vocabulary for given world affordances and searches six supplied three-role grammars using an empirical bigram coding score. Every action is decoded through the world-language interpreter. A separate deterministic test with an independent listener checks three unseen compositions after grounding and rejection of an unknown word before grounding. This is a finite protocol check, not a learned-general-language benchmark. Journals retain 256 observed events per agent; exact resumable checkpoints include random streams, weights, language and memories. The default interactive model is the 140-parameter linear sigmoid, selected on development results only; both architectures remain in the untouched comparison. The source files and protocol are hashed in the result.

Implementation checks cover repeatability, numerical boundedness, real parameter updates and freezing, temporal-order effects, resource accounting, newcomer learning, packet parsing, and the separation of imported proposals from observed simulator events. End-to-end browser inspection is outside this run.
