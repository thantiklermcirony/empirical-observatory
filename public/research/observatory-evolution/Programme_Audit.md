# A living Observatory for the whole programme

Independent programme/evidence audit and design proposal, 10 September 2026. Scope: the local programme, manuscript/test catalogs, history manifests, prior mathematical audits and current contribution/result records. No Site edits, external publication, new experiment or full manuscript proof audit occurred in this task. Upstream submission statuses below describe the saved evidence; live maintainer status was not re-fetched.

The programme's strongest unifying question is **what a scientific description must retain, and what access is required, to support a particular prediction or action**. That is a serious science-wide ambition. It can connect mathematical structure, scientific instruments, biology, cognition and AI without requiring identical mechanisms or a single numerical invariant across them.

The Observatory should become a place where descriptions encounter resistance: two apparently equivalent histories separate under a probe; a proposed geometry fails an assumption; a useful intervention exposes a missing state variable; a good-looking score fails a stronger comparison. The system then records what changed, why, and what remains unresolved. Its philosophical depth lies in making the relation between world, access, representation and action operational.

There is a distinction between a common language for research and an empirically established universal theory. The first is already a plausible organizing project. The second would require independently supported bridges and predictive achievements across domains. Merely being able to redescribe every failure after the fact is insufficient: the architecture must help select a better next test or representation at a measured cost.

The reusable engineering achievement is **a reproducible invariant violation, a limited repair, an independent oracle or differential check, and a preserved scope statement**. These are established scientific/software practices organized around the programme's questions. Their reuse is valuable without claiming that conventional techniques originate here.

## 3. Fixed research contracts, revisable descriptions

The Observatory should let ideas change without permitting completed tests to change their own meaning.

| Layer | Fixed for one scored run | Legitimately revisable |
|---|---|---|
| **Research contract** | System/population, permitted preparations/actions, observation access, future outcomes/horizon, units, loss, baselines, cost accounting, evaluation partition, stopping rule and success threshold. | A new scientific question or improved protocol creates a new version. Old results keep their original contract. |
| **Adaptive rule** | Which updates are allowed, what information triggers them, candidate/model capacity limits, search/tuning budget and promotion criteria. | Beliefs, parameter estimates, chosen probes, state features, partitions or policies can change by that rule. The complete path is logged. |
| **Scientific assumptions** | The assumptions attributed to the tested model/theorem at the time of the run. | Stationarity, sufficiency, scalar state, commutation, reversibility, isotropy, likelihood family, biological mechanism and sensor validity are challengeable. Revising one creates a model/theorem version and rechecks affected conclusions. |
| **Evidence record** | Source/data/code identities, predictions before reveal, observations, failures, exclusions, actual costs and review history. | New observations and corrections are appended. An erroneous record can be marked invalid with reason; it is not silently overwritten. |
| **Normative/operational constraints** | The actual authorized action scope, consent and resource limits under which the run occurred. | Future authorized scopes can differ. Model confidence alone does not enlarge them. |

An adaptive experiment does not freeze the answer or forbid learning. It freezes the rules by which learning will be judged. Discovery data can select a new representation; an untouched test then asks whether that choice helped. If a visitor changes the loss or sensor access after reveal, the interface should create a new exploration branch and retain the original failed test.

Even core assumptions are revisable. The statement that a predictive state identifies equivalent histories is a conditional mathematical characterization; its finite, measurable, computable usefulness is an additional obligation. “Store every history” cannot count as success without accounting for memory, query and measurement cost. A more expressive state should earn its complexity. A failed empirical application can reject the chosen representation or bridge without refuting a valid conditional theorem, but repeatedly rescuing the whole programme by unbounded scope changes would make its empirical ambitions empty. Public stopping rules prevent that.

## 4. A graph of declared relationships

“Holographic” should describe the explorable display and its multiple views. Unless an embedding is itself a measured object under a declared metric, node distance, height, rotation, color and glow have **no physical or evidential meaning**. A three-dimensional map is not a newly discovered geometry of science.

Use result-level nodes beneath papers. A minimal node records identity/version, kind, precise statement, assumptions, scope, source location, evidence artifacts, known counterexamples, status/date and next test. Keep distinct dimensions for mathematical status, empirical support, implementation maturity and upstream adoption. A paper can contain a valid theorem, an untested bridge and an obsolete claim simultaneously.

| Edge type | Meaning that must be inspectable |
|---|---|
| **Depends on / derives under** | Exact premises and the inference or proof location; no implication is asserted merely from shared language. |
| **Tests / supports within / conflicts with** | Which claim/version was tested, what outcome was observed, comparator and scope. A null or inconclusive result is not automatically refutation. |
| **Implements / reproduces** | Which mathematical or software behavior the code implements, or which original result was independently reproduced. |
| **Requires measurement / proposes test** | A design dependency or unexecuted research proposal, visibly distinct from evidence. |
| **Uses a pattern / analogy** | A useful conceptual connection; no logical implication or transferred empirical support. |
| **Supersedes / corrects** | The exact earlier claim and reason, preserving its source and original dates. A new manuscript title alone is insufficient. |

Examples: Graphiti → temporal architecture is principally a reusable state/time contract; its database tests do not validate biological memory. A NeuroGym aliasing reproduction exemplifies an observation-sufficiency problem; it does not prove every predictive-closure theorem. A redox fold equation → rescue-time ratio can be a conditional derivation with shared mobility; that edge becomes a biological prediction only after the model mapping is justified. UHL → consciousness remains a proposed bridge or analogy unless an actual derivation and discriminatory experiment are supplied.

When a premise changes, mark dependent claims “needs re-evaluation”; do not instantly mark unrelated applications false. Evidence from the same dataset/run must retain one provenance identity even when displayed along several edges. Cycles in the discovery workflow are useful feedback; cycles of citation do not create independent evidence. Default to a sparse authored map with a relationship explanation on selection, not a similarity graph presented as discovery.

## 5. What “self-improvement” must mean

There are several different capabilities. Name the one actually demonstrated.

| Capability | What must happen | Appropriate claim |
|---|---|---|
| **Interactive explanation** | A visitor changes controls or reveals a prerecorded distinction. | “Explore/replay a model or recorded result.” |
| **Adaptive inference/experiment selection** | A fixed rule updates beliefs and selects the next allowed probe in a fixed hypothesis space. | “The simulated policy adapts to observations.” |
| **State/model revision** | A permitted update changes the representation/model family after a detected failure and improves untouched continuation prediction or action. | “This state-revision procedure improves this benchmark.” |
| **Algorithmic improvement** | The system produces a changed learner/policy implementation, evaluated against the previous version and strong alternatives on a fresh sealed suite. | “The new version improved these measured outcomes at this total cost.” |
| **General scientific self-improvement** | Such improvements recur across independent tasks/domains without hidden evaluation access, escalating human intervention or unaccounted resources. | A longer-term research claim requiring a series of independent results. Nothing currently establishes it. |

Before promoting the bounded simulation beyond an explanation, require:

1. **A real limitation:** identify histories the initial representation aliases and a permitted future probe that distinguishes them. Synthetic ground truth may define the oracle, but the learner cannot read it. Include cases where no allowed probe can help.
2. **A measurable endpoint:** predeclare held-out prediction loss or decision regret, inference/calibration measures where meaningful, probe count/cost, memory and compute. A lower internal uncertainty score alone is not success.
3. **Strong matched baselines:** frozen initial policy, random probes, standard information/decision-value selection, a fixed richer-state or full-history method, and an ablation without state revision. All receive the same observations and actuation rules; oracle access is labeled separately as an upper bound.
4. **A bounded update:** specify candidate features/models and stopping criteria before test outcomes. Count failed searches and resets. Revealing hidden truth or manually choosing the correct state is an educational intervention, not autonomous discovery.
5. **Fresh evaluation:** lock predictions before reveal; evaluate unseen histories/continuations and independently seeded worlds. For a small finite system, enumerate the stated cases when feasible. Report paired uncertainty over independent units and every failure family. Repeated frames from one world are not independent trials.
6. **A practical advantage:** choose the minimum worthwhile improvement before running; show it against the strongest eligible comparison, not only a deliberately inadequate starting point. No silent trade of correctness for more sensors, storage, time or actuator access.
7. **Retention and transfer:** verify old valid cases still work, calibration does not collapse, and the improvement survives a changed nuisance setting. An automatic proposal is not promoted merely because its own tests approve it.
8. **Reproducibility and attribution:** export the contract, initial state, observations, proposed revisions, accept/reject decisions, seeds, costs and final evaluation. Distinguish human choices, prescribed rules and machine-generated proposals. Another implementation should be able to check the outcome.

For the first shipped simulation, “bounded adaptive-experiment simulation” is sufficient and accurate. It can demonstrate how a missing distinction becomes useful without claiming that it learns a new natural law. If its measurement likelihoods are supplied, posterior probabilities are conditional on those likelihoods; they are not empirically calibrated biological confidence.

## 6. How failure should change the atlas

Flight 01 is the worked example. Keep the original broad-advantage claim, its frozen threshold and the failed outcome connected. Record narrower observations—different baseline winners by context, agreement sometimes failing in the destination, and amplitude changes leaving direction intact—as descriptive findings. Propose destination-control features as a new hypothesis, not the confirmed explanation of those failures. The next experiment receives a new contract and holdout.

The same discipline applies to UHL: attach the explicit alternative-generator counterexample to the failed uniqueness inference, while retaining conditional projective/classification results with their stronger assumptions. Do not archive all geometry because one argument fails, or let a later correct result erase that counterexample. The graph should tell a history of improved precision.

This gives the programme a credible large ambition: an instrument for **finding when a scientific description stops being adequate, designing a discriminating test, and preserving what the result actually warrants**. Its scale can grow through many mechanisms and communities. Its success is measured by useful distinctions and independently checkable achievements, not the number of connections on its map.
